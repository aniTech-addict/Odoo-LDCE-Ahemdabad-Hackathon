# GlobeTrotter

1. Open the landing page and choose **Begin planning**.
2. Create a trip, select Paris and Amsterdam, and advance through the three-step wizard.
3. Open the itinerary builder and add activities from the live budget rail.
4. Drag activities across days, edit times inline, and remove an activity.
5. Open Budget to see the Recharts donut/bar views update from the same persisted store.
6. Open Calendar & timeline to review the same itinerary data.
7. Use Share trip to open the public magazine-style route; **Copy this trip** returns to trip creation.
8. Sign in accepts any email and password with 6+ characters; state persists in localStorage.

Run with `npm install && npm run dev`.
